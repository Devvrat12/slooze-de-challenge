# Slooze Data Engineering Challenge

### Electronics Supplier Intelligence — IndiaMART & Alibaba Scraper + EDA

**By: Devvrat Tiwari**

## Setup

```bash
python -m venv venv
venv\Scripts\activate      # Windows
pip install -r requirements.txt
python main.py
```

## Project Structure

- `scrapers/` — IndiaMART & Alibaba web scrapers
- `utils/` — Data cleaning & export helpers
- `eda/` — Exploratory data analysis & charts
- `data/` — Output data (generated on run)
